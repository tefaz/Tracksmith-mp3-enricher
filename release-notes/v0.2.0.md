Tracksmith now embeds word timings directly in MP3s while preserving line timing compatibility. This release also provides the first Linux AppImage and Debian installers.

- Find and embed lyrics, individually or in batch.
- Create and adjust line and word timings. Standard SYLT carries line boundaries and word starts; an additional embedded frame preserves exact word ends and editing data. Word timings travel with the MP3, without a required companion file.
- Nightwave can read line-only, word-timed and mixed-line files using its existing karaoke reader. Existing line-only files continue to work.
- Find relevant album cover art, including batch suggestions with visual review before saving.
- Find and edit other song metadata.
- Remove workspace recovery, startup recovery prompts, and redundant Tools/View menu entries. Unsaved edits stay in memory until saved or discarded.
- Reorganize the README around lyrics, timing and cover art, with clear storage and installation instructions.

Download `Tracksmith-0.2.0-x86_64.AppImage` or `tracksmith_0.2.0_amd64.deb`. `SHA256SUMS` contains checksums for both installers.

The installers include Python and GUI dependencies for Linux x86_64 with glibc 2.34+ (Ubuntu 22.04+/Debian 12+). FFmpeg and a working desktop audio/graphics environment are required; the Debian package declares its system dependencies. Optional CPU analysis packages can be installed with `tracksmith --install-ai` or `./Tracksmith-0.2.0-x86_64.AppImage --install-ai`. Model files download on first analysis. Source installation remains available for other analysis configurations.

Validation: all 278 source tests passed, lint passed, and real generated MP3s were read successfully through Nightwave’s existing karaoke parser for line-only, word-timed and mixed lines. Installer launch and embedded-timing checks were performed using the bundled runtime on CachyOS Linux.
